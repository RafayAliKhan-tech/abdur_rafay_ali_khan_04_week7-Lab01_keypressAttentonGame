# 🎯 Reaction Time Game (Keypress Attention Game)

## 📌 Project Description

This project is a simple **Reaction Time / Keypress Attention Game** developed for HCI Lab practice.
It measures how quickly a user can respond to visual stimuli (letters and numbers) using keyboard input.

The game evaluates **human attention and response speed** by calculating reaction times over multiple rounds.

---

## 🎮 Gameplay Instructions

1. Click the **Start Game** button
2. A random character will appear on the screen:

   * 🔤 Letter (A–Z)
   * 🔢 Number (0–9)
3. Press the correct key as fast as possible:

   * Press **A** → if the character is a **Letter**
   * Press **L** → if the character is a **Number**
4. The game will:

   * Show if your answer is **Correct ✅ or Wrong ❌**
   * Display your **reaction time**
5. After all rounds, your **average reaction time** will be shown

---

## ⚙️ Features

* 🎯 Random stimulus generation (letters & numbers)
* ⌨️ Real-time keyboard input detection
* ✅ Instant feedback system (Correct / Wrong)
* ⏱ Reaction time calculation (milliseconds)
* 📊 Average response time at the end
* 🔁 Multiple rounds gameplay
